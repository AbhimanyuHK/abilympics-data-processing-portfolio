# Access Query Specifications

| ID | Query | Expected purpose |
|---|---|---|
| Q01 | Member Reservations | List reservations for a selected member |
| Q02 | Reservations by Country | Aggregate reservations by member country |
| Q03 | Travel Duration | Calculate trip duration |
| Q04 | Destination Revenue | Aggregate travel price by destination |
| Q05 | Member History | Show chronological travel history |
| Q06 | Cancellations | Identify cancelled reservations |
| Q07 | Airline Utilization | Count reservations by airline |
| Q08 | Member Spend | Aggregate member travel spend |
| Q09 | Upcoming Travel | Show future travel |
| Q10 | Country Summary | Combine country-level counts |
| DQ01 | Duplicate Detection | Identify duplicate candidates |
| DQ02 | Missing Required Values | Identify incomplete records |
| DQ03 | Invalid References | Identify unmatched references |
| DQ04 | Invalid Dates | Identify impossible date ranges |
| DQ05 | Invalid Status | Identify values outside the approved domain |

For each query document inputs, tables, joins, calculated fields, grouping/sorting, expected result, and a validation sample.
