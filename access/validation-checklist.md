# Access Validation Checklist

## Database
- [ ] All tables created
- [ ] Primary keys configured
- [ ] Relationships configured
- [ ] Referential integrity checked
- [ ] Required fields configured
- [ ] Appropriate data types configured

## Queries
- [ ] Required queries run
- [ ] Joins verified
- [ ] Calculations verified
- [ ] Aggregations verified
- [ ] Data-quality queries return known exceptions

## Forms
- [ ] Search works
- [ ] Data entry works
- [ ] Invalid input is rejected or flagged
- [ ] Update workflow works
- [ ] Navigation works

## Reports
- [ ] Data matches source queries
- [ ] Totals verified
- [ ] Formatting checked
- [ ] Filters/parameters checked

## Final
- [ ] No broken controls
- [ ] No missing objects
- [ ] Database opens cleanly
- [ ] Sample records manually verified
- [ ] Timed run recorded
