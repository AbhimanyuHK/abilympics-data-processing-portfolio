# Access Forms

The interface track demonstrates practical data-entry and search workflows.

## Required forms

### F01 — Member Search
Search by member ID, name, country, or status and display matching reservations.

### F02 — Reservation Entry
Select a member and schedule, enter reservation details, validate required fields and status.

### F03 — Reservation Update
Locate a reservation, update permitted fields, and revalidate before saving.

### F04 — Administrator Dashboard
Navigate to search, entry, update, reports, data-quality queries, and exit.

## Usability checks
- Clear labels
- Consistent navigation
- No unnecessary fields
- Understandable validation messages
- Technical database details hidden from normal users
