# Access Queries

Build saved Access queries against the practice reservation database.

## Query groups
### Search and retrieval
- member search
- reservation search
- upcoming travel
- member reservation history

### Aggregation
- reservations by country
- destination revenue
- member spend
- airline utilization
- cancellation summary

### Data quality
- duplicate candidates
- missing required values
- invalid references
- invalid date ranges
- invalid status values

## Naming
Use Q01_, Q02_, Q03_ for functional queries and DQ01_, DQ02_ for data-quality queries.
