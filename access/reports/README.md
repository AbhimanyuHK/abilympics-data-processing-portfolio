# Access Reports

Reports should be based on saved queries and provide reproducible output.

## Required reports
- Reservation Summary
- Member Travel History
- Destination Revenue
- Country Summary
- Airline Utilization
- Cancellation Summary
- Data Quality Exceptions

## Requirements
- meaningful title
- reporting/filter context
- clearly labeled columns
- totals where appropriate
- consistent formatting
- source query documented
- no manually typed calculated totals

## Verification
1. Run the underlying query.
2. Check representative records.
3. Verify totals.
4. Verify filters.
5. Check for unexpected blanks/errors.
