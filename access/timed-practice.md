# Access Timed Practice

## 60-minute challenge

### 0–10 min — Database
Create/import tables, set primary keys, create relationships.

### 10–25 min — Queries
Build core search queries, aggregations, and at least two validation queries.

### 25–45 min — Interface
Build member search, reservation entry, reservation update, and basic navigation.

### 45–55 min — Reports
Build reservation summary, one aggregation report, and exception report.

### 55–60 min — Verification
Run validation checks, check totals, test representative form actions, save the final database.

## Self-review
Score yourself on correctness, completeness, validation, usability, and time discipline.
Record failures and repeat the challenge until execution becomes predictable.
