# LibreOffice Base Reports

Create reports from saved queries.

## Required reports

- Reservation Summary
- Member Travel History
- Destination Revenue
- Country Summary
- Airline Utilization
- Cancellation Summary
- Data Quality Exceptions

## Verification

Every report should be traceable to a saved query.

Check:
- totals
- filters/parameters
- date formatting
- numeric formatting
- representative records
- exception treatment
