# LibreOffice Base Timed Practice

## 60-minute challenge

0–10: import and table setup
10–20: keys and relationships
20–35: queries
35–48: forms
48–55: reports
55–60: validation and reconciliation

## Self-review

Record:
- completion time
- missing requirements
- incorrect results
- validation failures
- usability issues
- steps that consumed excessive time

Repeat until the workflow is predictable.
