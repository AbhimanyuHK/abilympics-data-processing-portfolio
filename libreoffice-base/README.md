# LibreOffice Base Competition Track

This track provides an open-source database alternative for practicing the same relational database concepts used in the portfolio.

## Workflow

Source CSV
→ import
→ tables
→ relationships
→ queries
→ forms
→ reports
→ validation
→ final verification

## Core entities

- COUNTRY
- MEMBER
- TRAVEL
- AIRLINE
- SCHEDULE
- RESERVATION

## Important

LibreOffice Base is an additional practice track. It does not replace Microsoft Access preparation.

The goal is to strengthen transferable relational database skills:
- table design
- primary/foreign keys
- relationships
- SQL
- data validation
- forms
- reports
- reproducibility

See the build guide for the recommended setup.
