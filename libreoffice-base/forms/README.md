# LibreOffice Base Forms

Build practical forms using the same functional requirements as the Access track.

## Required forms

### F01 Member Search
Search members and inspect related reservations.

### F02 Reservation Entry
Create a reservation using valid member and schedule references.

### F03 Reservation Update
Locate and update an existing reservation.

### F04 Administrator Navigation
Provide navigation to forms, queries, reports, and data-quality checks.

## Validation

Test:
- required fields
- valid references
- approved status values
- valid dates
- duplicate candidates

Focus on functional correctness and usability rather than visual decoration.
