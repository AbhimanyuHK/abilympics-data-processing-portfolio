# LibreOffice Base Validation Checklist

## Database
- [ ] Tables created
- [ ] Primary keys configured
- [ ] Data types verified
- [ ] Relationships configured
- [ ] Referential integrity checked

## Queries
- [ ] Functional queries run
- [ ] Aggregate results verified
- [ ] Data-quality queries run
- [ ] Expected counts checked

## Forms
- [ ] Search works
- [ ] Reservation entry works
- [ ] Invalid values are rejected or flagged
- [ ] Update workflow works
- [ ] Navigation works

## Reports
- [ ] Reports use saved queries
- [ ] Totals verified
- [ ] Formatting checked
- [ ] Exceptions visible

## Final
- [ ] Source preserved
- [ ] Reconciliation completed
- [ ] Representative records sampled
- [ ] Database saved and reopened successfully
