# Competition Overview

## International Abilympics — Helsinki 2027

This document records the official information currently available for the **Data Management and Processing** skill.

### Current Skill Description

The skill involves designing and developing database-driven applications using a DBMS. The published description highlights:

- Database design
- Query implementation
- Data-processing logic
- Relational databases
- Data normalization
- Performance optimization
- Security
- Scalability
- Applying DBMS tools to functional requirements
