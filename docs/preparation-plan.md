# Preparation Plan

## Objective

Build competition-ready speed and accuracy across database design, SQL, data processing, interfaces, and reporting.

## Stage 1 — Database Fundamentals

- Entity identification
- Attributes and data types
- Primary keys
- Foreign keys
- Cardinality
- Referential integrity
- Normalization
- Constraint design

## Stage 2 — SQL

- SELECT
- Filtering
- Sorting
- Joins
- Aggregations
- GROUP BY / HAVING
- Subqueries
- CTEs
- CASE expressions
- Date and time processing
- Data modification
- Validation queries
- Reporting queries

## Stage 3 — Data Processing

- Import raw data
- Standardize fields
- Detect duplicates
- Handle missing values
- Validate reference data
- Apply business rules
- Produce clean datasets
- Record rejected/error records

## Stage 4 — Application

- User forms
- Search and filtering
- Data-entry validation
- Administrator workflows
- Reports
- Usability checks

## Stage 5 — Timed Practice

Each mock task should record:

- Start time
- End time
- Requirements completed
- Defects found
- Defects fixed
- SQL errors
- Data-quality issues
- Final verification time

## Stage 6 — Review

After every task:

1. Identify avoidable errors.
2. Identify slow steps.
3. Improve reusable templates.
4. Update the checklist.
5. Repeat the task under tighter time constraints.
