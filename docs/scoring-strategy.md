# Assessment and Execution Strategy

This document is a preparation framework, not an official 2027 scoring rubric.

## Priority Areas

### 1. Accuracy

Verify:

- Table relationships
- Keys
- Constraints
- Query results
- Calculated values
- Data types
- Null handling
- Business rules

### 2. Completeness

Before submission, confirm that every requirement has been implemented and tested.

### 3. Usability

Interfaces should make common operations obvious and reduce unnecessary manual steps.

### 4. Data Integrity

Check for:

- Duplicate records
- Orphan records
- Invalid references
- Invalid dates
- Missing required values
- Invalid status transitions

### 5. Performance

For larger datasets, check:

- Query execution time
- Index usage where appropriate
- Avoidable repeated calculations
- Efficient joins and filtering

### 6. Verification

Reserve explicit time at the end of every timed task for:

- Smoke testing
- Query-result verification
- Form testing
- Report testing
- Boundary cases
- Final cleanup

## Personal Practice Metric

For each mock task, track:

`Completion %`, `Defect count`, `Verification time`, and `Total execution time`.

The objective is to improve repeatable execution rather than simply finishing one exercise.
