# Excel Reports

The reporting track converts validated data into decision-ready summaries.

## Required practice outputs
- Reservation summary
- Country/member summary
- Destination revenue summary
- Cancellation summary
- Airline utilization
- Data-quality exception summary

## Report design
Each report should clearly identify:
- reporting period
- source dataset/version
- filters applied
- metric definitions
- refresh date
- exception treatment

Prefer formulas, PivotTables, structured tables, and documented assumptions over manually typed totals.
