# Mock Competition — End-to-End

## Objective
Complete a database-processing task from requirements to verified output under a fixed time limit.

## Workflow
1. Read requirements.
2. Identify entities.
3. Design relationships.
4. Create database.
5. Import/create data.
6. Build queries.
7. Implement interface.
8. Produce reports.
9. Validate results.
10. Perform final review.

## Initial Timebox
3 hours.

## Final Review
- Every requirement addressed
- Relationships verified
- Constraints verified
- Queries tested
- Reports tested
- Invalid data checked
- Boundary cases checked
- Duplicate records checked
- Final outputs saved
- Assumptions documented

Create results.md after each mock with timing, defects, corrections, and lessons learned.
