# Mock Competition Task Brief

## Scenario

An international organization maintains members, travel programs, airline schedules, and reservations. You have received a partially documented requirement and a set of source records.

Build a working database solution that supports data entry, search, reservation processing, and reporting.

## Required Outputs

### Database
- Relational schema
- Primary and foreign keys
- Appropriate constraints
- Sample/source data

### Processing
- Clean and validate source records
- Detect duplicates
- Detect invalid references
- Produce an exception report

### Queries
Provide at least:
- Member reservation history
- Reservations by country
- Travel duration
- Destination summary
- Airline utilization
- Cancellation report

### Interface
Provide:
- Member search
- Reservation search
- Reservation entry/update
- Administrative view

### Reports
Produce:
- Reservation summary
- Data-quality exception report

## Final Verification

Before stopping, verify every required output and record the remaining defects.

## Recommended Timebox

3 hours.

The task is a self-created practice exercise and is not an official competition task.
