# Competition-Day Preparation Checklist

## Before starting
- [ ] Read the complete task before building
- [ ] Identify required outputs
- [ ] Mark mandatory vs optional requirements
- [ ] Identify source tables/files
- [ ] Identify validation rules
- [ ] Estimate time per section

## During the build
- [ ] Save frequently
- [ ] Preserve raw data
- [ ] Validate incrementally
- [ ] Avoid unnecessary formatting
- [ ] Keep object/query names consistent
- [ ] Record assumptions

## Before final submission
- [ ] Run all required outputs
- [ ] Verify totals
- [ ] Check representative records
- [ ] Check relationships
- [ ] Check forms
- [ ] Check reports
- [ ] Check data-quality exceptions
- [ ] Confirm required files are present

## Mindset

Work in this order:

**Understand → Structure → Process → Validate → Present → Verify**

Do not optimize for appearance before correctness.
