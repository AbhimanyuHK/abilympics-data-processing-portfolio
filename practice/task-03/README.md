# Task 03 — Application and Reporting

## Objective
Turn the database into a usable DBMS application.

## Requirements
- Member search form
- Reservation entry form
- Reservation status update
- Required-field validation
- Search/filter capability
- Administrator view
- Summary report
- Data-quality exception report

## Initial Time Target
75 minutes.

Test valid input, missing input, invalid foreign keys, invalid dates, duplicate reservations, cancellations, and empty search results.
