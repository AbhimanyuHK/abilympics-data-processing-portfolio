# Task 01 — Relational Database Foundation

## Objective
Build the Travel Reservation database from written requirements.

## Requirements
1. Identify entities and attributes.
2. Define primary and foreign keys.
3. Establish cardinality.
4. Normalize to 3NF.
5. Create tables and constraints.
6. Insert sample records.
7. Run integrity checks.
8. Document assumptions.

## Deliverables
- Relationship diagram
- Table definitions
- Sample data
- Constraint verification
- Design notes

## Initial Time Target
45 minutes.
