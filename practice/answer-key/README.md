# Practice Answer Key

This folder contains expected results used to verify timed exercises.

## Verification principle

An answer key should verify the result, not prescribe one implementation.

Equivalent SQL, Excel formulas, Access queries, or other correct relational approaches are acceptable when they produce the same validated result.

## Recommended checks

- exact row counts
- aggregate totals
- sorted result sets
- duplicate candidates
- exception counts
- reconciliation totals

Do not use the answer key during the first timed attempt. Use it during review.
